# Chhattisgarh Phase 1

Chhattisgarh Phase 1 publishes district-level GPS tracking guides for all 33 current districts in the Government of Chhattisgarh listing.

Each route uses `/gps-tracker/chhattisgarh/{district}` and includes:

- English and Hindi-intent GPS tracking keywords.
- Four curated local discovery locations and a unique operating profile.
- Canonical metadata with one H1.
- WebPage, Service, FAQ and breadcrumb structured data.
- Links from the Chhattisgarh state hub and automatic sitemap inclusion.

The automated source checker locks the 33-district inventory and official source. The rendered-page checker validates canonicals, indexability, schema, sitemap membership and hub links for every district route.
