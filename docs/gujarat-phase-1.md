# Gujarat Phase 1 SEO

Phase 1 publishes district-level GPS tracking guides for all 34 current Gujarat districts. The inventory includes Vav-Tharad, which was carved out of Banaskantha and is treated as a separate district rather than using the older 33-district structure.

Each district page includes English and Gujarati-intent keywords, four local discovery locations, unique fleet and route context, canonical metadata, WebPage, Service, Breadcrumb and FAQ structured data, sitemap inclusion and a link from the Gujarat state hub.

Region names are editorial navigation groups rather than claims of an additional administrative tier. The pages are planning guides and do not claim a local NAVII GPS office or guaranteed installation availability.

Run `npm run seo:check:source` after data or routing changes. Run `npm run build && npm run seo:check` before release to verify all rendered pages, links, metadata and schema.
