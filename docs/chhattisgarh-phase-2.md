# Chhattisgarh Phase 2

Chhattisgarh Phase 2 adds 66 curated priority city and town guides—two within every current district.

Each route uses `/gps-tracker/chhattisgarh/{district}/{city}` and includes:

- English and Hindi-intent GPS tracking keywords.
- Unique local operating context and route checks.
- Canonical metadata with one H1.
- Place-scoped Service, FAQ and breadcrumb structured data.
- Links from the Chhattisgarh hub, parent district and paired location.

The automated source checker locks the reviewed district-to-city mapping. The rendered-page checker validates canonicals, indexability, schema, sitemap membership and internal links for every city route.
