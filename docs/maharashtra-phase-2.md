# Maharashtra Phase 2 SEO

Phase 2 publishes 72 curated priority city and town guides: two locations inside each of Maharashtra's 36 current districts. District headquarters are excluded where they would duplicate the parent district URL.

Each page includes English and Marathi-intent GPS tracker keywords, a unique local operating workflow, canonical metadata, WebPage, Service, Breadcrumb and FAQ structured data, and links to the Maharashtra hub, parent district and paired location.

The reviewed inventory is based on the Phase 1 district location set and checked against official Maharashtra district and urban-local-body directories. These pages are planning guides and do not claim a local NAVII GPS office or guaranteed installation availability.

Run `npm run seo:check:source` after data or routing edits. Run `npm run build && npm run seo:check` before release so all 72 rendered pages, sitemap entries and internal-link paths are verified.
