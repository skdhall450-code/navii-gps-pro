# Madhya Pradesh Phase 1

Madhya Pradesh Phase 1 publishes district-level GPS tracking guides for all 55 current districts in the Government of Madhya Pradesh directory, including Maihar, Mauganj and Pandhurna.

Each route uses `/gps-tracker/madhya-pradesh/{district}` and includes:

- English and Hindi-intent GPS tracking keywords.
- Four curated local discovery locations and a unique operating profile.
- Canonical metadata with one H1.
- WebPage, Service, FAQ and breadcrumb structured data.
- Links from the Madhya Pradesh state hub and automatic sitemap inclusion.

The automated source checker locks the 55-district inventory and official source. The rendered-page checker validates canonicals, indexability, schema, sitemap membership and hub links for every district route.
